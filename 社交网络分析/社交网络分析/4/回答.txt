一.问题分析
选择指标：
1.度中心性& 加权度:衡量一个节点直接连接的邻居数量（度）以及互动的总强度（加权度）。度高代表“认识的人多”（交际花），加权度高代表“互动的总量大”（活跃分子）。这是识别社团活跃骨干的基础。
2.介数中心性：衡量一个节点出现在网络中其他节点对之间最短路径上的频率介数高的人可能认识的人不是最多，但他是不同小圈子之间的桥梁。如果他离职，社团内部可能会断连或分裂。
3.特征向量中心性：衡量一个节点是否与“重要”的节点相连。如果一个成员虽然互动不多，但互动的对象都是社长、部长等核心人物，他的特征向量中心性会很高，意味着由于他处于核心圈层，具有较高的隐性影响力。
注意事项：在处理代码中生成的互动频次权重时，必须区分强度与距离的概念，这是SNA分析中最容易出错的地方：
	作为“强度: 在计算加权度和特征向量中心性时，权重代表联系的紧密程度。权重越大，关系越强，影响力越大。
	作为“距离”: 在计算介数中心性和接近中心性时，算法通常基于“最短路径”。如果直接使用互动频次作为权重，算法会认为权重 10 的边比权重 1 的边“更长/更难通过”，这与逻辑相悖（互动多应该联系更紧密，距离更短）。因此，在计算涉及路径的指标前，需对权重取倒数，构建“距离”属性。

三.结果分析
1. 核心节点对比与重叠分析
重叠节点：Node 42, Node 4, Node 13
特征： 这些节点在多个指标中反复出现。
Node 13 是极其特殊的“隐形大佬”。请注意，它没有出现在无权度中心性（Degree）的前 5 名中（意味着它认识的人数不是最多的），但在加权度（Weighted Degree, 1.0000）、加权接近中心性和加权特征向量中心性中均排名 第一。
共同特征： 这说明 Node 13 虽然社交圈子可能不如 Node 17 广泛，但与他/她互动的人都是核心成员，且互动极度频繁（权重高）。他是社团互动的“质量”中心。Node 4 和 Node 42 则是“数量”与“质量”兼备的全面型人才，在无权和加权指标中均表现优异。
（2）差异节点：特定角色
“弱关系”桥梁 (Node 17)：
现象： Node 17 在无权度中心性和无权介数中心性中均排名第一（或并列第一），但在所有加权指标中均未进入前 5。
解释： Node 17 是典型的“交际花”。他认识的人最多，且在结构上处于很多人的中间位置。但是，他与这些人的互动频次（权重）普遍较低。他是社团的“泛泛之交”，能连接不同的小圈子，但关系不够铁。
高效传输者 (Node 6)：
现象： Node 6 在加权接近中心性（Closeness）和加权介数中表现突出。
解释： 虽然 Node 6 可能不是互动总量最大的，但他所处的位置让信息通过他传播的“阻力”最小（基于 1/weight 的距离最短）。
2.社团运营场景的实际指导意义
Node 13：Node 13 与核心圈层关系最铁，拥有最高话语权。社团换届、推行新规时，必须先搞定 Node 13，只要他同意，核心圈子就会响应。
Node 42 & Node 4：这两人既有人脉广度（度高）又有深度（加权高），且占据信息通道（介数高）。适合担任活动总负责人，既能调动人手，又能确保信息上传下达无误。
Node 17：当需要向边缘成员或不同部门的“僵尸粉”传达活动通知时，让 Node 17 去转发。虽然大家跟他关系不深，但他能触达那些核心圈子接触不到的人。
Node 6：需要临时集合或突发情况通知时，由 Node 6 发起联络链条，因为他在加权网络中的平均路径最短，效率最高。
