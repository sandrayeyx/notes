### 新策略：利用 Java I/O 直接读取文件 (LFI)



既然无法通过 Shell 执行命令（RCE），我们退而求其次，尝试利用 OGNL **直接调用 Java 的文件读取类**。

OGNL 允许我们 `new` 一个对象。只要 `java.io.File` 和 `java.util.Scanner` 没有被禁用，我们就可以像写 Java 代码一样直接读取服务器上的文件，而不需要通过 `/bin/bash`。
